# 조교급여대장 (Payroll Manager)

학원 조교/강사의 출퇴근 기록을 바탕으로 주휴수당, 야간·공휴가산수당, 세금(3.3% 프리랜서 / 4대보험 / 커스텀)을 자동 계산하고, 임금명세서와 급여대장 엑셀 파일을 생성하는 급여 관리 웹앱입니다.

## 주요 기능

- 직원(조교) 정보 및 근무 스케줄 관리
- 출퇴근 기록 파일(xlsx/csv) 업로드 및 자동 파싱
- 주휴수당 / 야간근로수당 / 공휴가산수당 / 유급연차수당 자동 계산
- 3.3% 프리랜서, 4대보험, 커스텀 세율 정산 지원
- 임금명세서 인쇄 및 PDF 저장
- **엑셀(.xlsx) 급여대장 내보내기** — 대시보드, 급여대장, 직원별 상세명세, 근태기록까지 포함된 서식 있는 다중 시트 워크북
- 브라우저 로컬 데이터 검증 및 구버전 저장 데이터 자동 마이그레이션
- 저장 데이터 손상 시 직전 정상본을 이용한 복구

## 데이터 저장 및 안전성

이 앱은 별도 서버/DB 없이 브라우저 `localStorage`를 사용합니다.

현재 저장 계층은 다음 보호 기능을 제공합니다.

- 앱 시작 시 직원/급여대장 데이터 형식 검증
- 기존 `payroll_employees`, `payroll_reports` 데이터의 새 저장 포맷 자동 이전
- 저장 직전 데이터 검증
- 최신 저장본이 손상된 경우 마지막 정상 저장본으로 자동 복구
- 초기 앱 로딩 중 빈 배열이 기존 저장 데이터를 덮어쓰지 않도록 보호
- 브라우저 저장 실패/복구 발생 시 화면 상단 경고 표시

> **개인정보 주의**  
> 직원 데이터에는 주민등록번호와 계좌번호가 포함될 수 있습니다. 현재 브라우저 저장 데이터 자체는 암호화되어 있지 않으므로 공용 PC에서 사용하지 말고, 전체 백업 기능을 이용해 별도의 안전한 위치에 주기적으로 백업하는 것을 권장합니다.

## 기술 스택

- React 19 + TypeScript + Vite
- Tailwind CSS
- xlsx-js-style (출퇴근 파일 파싱 및 서식 있는 엑셀 급여대장 생성)
- jsPDF / html2canvas-pro (문서/PDF 출력)
- date-fns, framer motion(Motion), lucide-react
